Basemap (CARTO)

Enter your CARTO API key to load the basemap.
The key is saved only in this browser. CARTO takes it as a ?key= parameter on the /rastertiles/ URL. Edit the template if yours differs ({style}, {key}, {z}/{x}/{y} are replaced).

Import G25 data

Real G25 files have no coordinates. Populations are placed by name from a built-in world table (East Asia, Africa, Americas, Siberia, Oceania…). Any unplaced population is listed after import: add it in the box above and press Add rows again.
Data: Eurogenes Global25 scaled population averages (modern + ancient), built in. Map positions are approximate: country or ethnic-region centres by name, not sample sites. Populations I could not place appear in the table and chart but not on the map.
